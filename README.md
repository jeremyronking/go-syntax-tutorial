# GoTour

An interactive Go syntax & toolchain tutorial. This implementation corresponds
to [issue #1](https://github.com/jeremyronking/go-syntax-tutorial/issues/1)
and was generated by working through every phase issue (#2 → #20) in order,
one commit per issue.

## Prerequisites

- Node.js **≥ 20**
- pnpm **≥ 10**
- (Optional) Docker, for building/running the production proxy image

## Commands

```sh
pnpm install        # install dependencies
pnpm dev            # start Vite dev server on http://localhost:5173
pnpm build          # type-check + production build to ./dist
pnpm preview        # serve the production build on http://localhost:5173
pnpm lint           # ESLint (typescript-eslint + react + react-hooks)
pnpm typecheck      # tsc --noEmit
```

The dev server proxies `/api/compile` to `https://play.golang.org/compile`
through Vite. Override with `PLAYGROUND_UPSTREAM=...` in the environment.

## Keyboard shortcuts

| Action | Shortcut |
|---|---|
| Open command palette | `Cmd/Ctrl + K` |
| Run the focused lesson | `Cmd/Ctrl + Enter` |
| Skip stream replay animation | visible button while replaying |
| Close palette / dialog | `Esc` |

`prefers-reduced-motion: reduce` is honored — the stream-replay animation
is skipped automatically.

## Stack

- Vite 5 + React 18 + TypeScript (strict, zero `any` in `src/`)
- Tailwind CSS (dark-first; toggle persists to `gotour:v1:theme`)
- Monaco editor (lazy-loaded; code-split out of the main bundle)
- Zustand for state, Fuse.js for search
- `localStorage` under the `gotour:v1` namespace for persistence
- React Router v6

## Lessons

The full registry lives in `src/content/lessons/`. Each lesson declares a
`runMode` (`playground`, `terminal`, or `annotated`). Playground lessons
round-trip through the live Go Playground; terminal lessons are pre-baked
command + output pairs.

### A — Language fundamentals (7 lessons)
- `hello-world` — Hello, world & program structure
- `go-run-vs-build` — `go run` vs `go build` (brief)
- `variables` — Variables: `var`, `:=`, multiple assignment, blank identifier
- `constants-iota` — Constants & `iota` (bit-flag pattern, expression repetition)
- `basic-types` — Basic types, zero values, type conversions
- `strings-runes-bytes` — Strings, runes, bytes; UTF-8 iteration with `range`
- `numeric-types` — Numeric types, overflow, untyped constants

### B — Control flow (7 lessons)
- `if-statement` — `if` (incl. init statement)
- `for-loop` — `for` (the only loop)
- `loop-variable-capture` — Loop variable capture (pre-1.22 vs 1.22+)
- `switch` — `switch` (no fallthrough, expression-less, multi-value cases)
- `type-switch` — `type switch`
- `defer` — `defer` (LIFO, argument evaluation, gotchas in loops)
- `labels-goto` — `goto`, labels, labeled `break`/`continue`

### C — Composite types (5 lessons)
- `arrays` — Arrays (fixed length, value semantics)
- `slices` — Slices (header, `append`, three-index slicing, `copy`, aliasing)
- `maps` — Maps (zero value is nil, comma-ok, deletion, iteration order)
- `structs` — Structs (composite literals, field tags, anonymous fields, comparability)
- `pointers` — Pointers (no arithmetic, `new`, address of a composite literal)

### D — Functions (4 lessons)
- `functions` — Functions, multi-return, named returns, naked `return`
- `variadic` — Variadic functions, slice-spread with `...`
- `closures` — First-class functions & closures
- `methods` — Methods, value vs pointer receivers, method sets, addressability

### E — Interfaces & polymorphism (4 lessons)
- `interfaces` — Interfaces, implicit satisfaction, the empty interface (`any`)
- `type-assertions` — Type assertions, comma-ok form, type switches revisited
- `embedding` — Embedding (struct, interface, method promotion)
- `stdlib-interfaces` — Common stdlib interfaces: `error`, `Stringer`, `io.Reader`/`Writer`

### F — Generics (3 lessons)
- `type-parameters` — Type parameters, type inference
- `constraints` — Constraints, `comparable`, `~` underlying-type, type sets
- `when-not-generics` — When *not* to reach for generics

### G — Errors, panic, recover (3 lessons)
- `error-interface` — The `error` interface, sentinel errors, `errors.Is` / `errors.As`
- `error-wrapping` — Wrapping with `fmt.Errorf("...: %w", err)`
- `panic-recover` — `panic` / `recover` and when each is appropriate

### H — Concurrency (7 lessons)
- `goroutines` — Goroutines (cost, lifecycle)
- `channels` — Channels: unbuffered vs buffered, send/receive
- `close-range` — `close`, `range` over channels, nil channel behavior
- `select` — `select` (default case, timeouts with `time.After`)
- `sync-mutex` — `sync`: `Mutex`, `RWMutex`, `WaitGroup`, `Once`, `Cond`
- `atomics` — `sync/atomic` and the memory model in one paragraph
- `context` — `context.Context` — cancellation, deadlines, values (with anti-patterns)

### I — Packages & project layout (4 lessons)
- `packages-visibility` — Packages, exported vs unexported (capitalization rule)
- `init-order` — `init()` order, package-level variable initialization
- `internal-modules` — `internal/` directories, import paths, `go.mod` module path
- `embed-files` — `//go:embed`

### J — Reflection & low-level (4 lessons)
- `reflect-basics` — `reflect` basics — `TypeOf`, `ValueOf`, kind vs type
- `unsafe-pointer` — `unsafe.Pointer` and `unsafe.Sizeof` (mention, don't encourage)
- `cgo` — `cgo` (one-paragraph awareness page)
- `build-tags` — Build tags `//go:build` and conditional compilation

### K — Toolchain (15 lessons)
- `toolchain-build` — `go run`, `go build`, output paths, `-o`
- `toolchain-install` — `go install` and `GOBIN`
- `toolchain-modules` — `go mod init` / `tidy` / `get` / `why` / `graph` / `replace` / `vendor`
- `toolchain-workspaces` — `go work` multi-module workspaces
- `toolchain-test` — `go test`: table tests, subtests with `t.Run`, `-run` regex, `t.Parallel`
- `toolchain-bench-fuzz` — `go test`: benchmarks, examples, fuzzing (`-fuzz`)
- `toolchain-race-cover` — `go test -race`, `-cover`, `-coverprofile`, `go tool cover`
- `toolchain-fmt` — `go fmt` / `gofmt` / `goimports`
- `toolchain-vet` — `go vet` and common analyzers
- `toolchain-doc` — `go doc` and pkg.go.dev conventions
- `toolchain-generate` — `go generate` directives
- `toolchain-env` — `go env`, `GOPATH`, `GOMODCACHE`, `GOPROXY`, `GOPRIVATE`, `GOFLAGS`
- `toolchain-cross-compile` — Cross compilation: `GOOS`/`GOARCH` matrix, `CGO_ENABLED=0`
- `toolchain-ldflags` — `-ldflags` (stamping versions), `-trimpath`, build modes
- `toolchain-pprof` — `go tool pprof` and `go tool trace`
## Deploying the proxy

In production, the browser cannot call the Playground directly (CORS), so
the app expects a small server that exposes `POST /api/compile` and
forwards to the upstream Playground. The default upstream is
`https://play.golang.org/compile`; override with `PLAYGROUND_UPSTREAM`.

### Local

```sh
pnpm server:dev       # tsx watch on :8787
pnpm server:build     # tsc -> server/dist
PORT=8787 PLAYGROUND_UPSTREAM=https://play.golang.org/compile node server/dist/index.js
```

Smoke-test:

```sh
bash server/smoke.sh http://localhost:8787/api/compile
```

### Docker

```sh
docker build -t gotour-server server/
docker run --rm -p 8787:8787 -e PLAYGROUND_UPSTREAM=https://play.golang.org/compile gotour-server
```

### Fly.io (one-liner)

```sh
fly launch --image-label org.opencontainers.image.title=gotour-server --internal-port 8787 \
  --env PLAYGROUND_UPSTREAM=https://play.golang.org/compile
fly deploy
```

### Render

Create a new **Web Service** from the repo, root directory `server/`,
environment `Node`, build command `pnpm install && pnpm build`, start
command `node dist/index.js`. Add env var `PLAYGROUND_UPSTREAM`.

## Adding a new lesson

See `CONTRIBUTING.md` for the full workflow. The short version:

1. Add a `Lesson` literal in `src/content/lessons/section-X.ts`.
2. Import it in `src/content/lessons.ts` and add it to the array.
3. If it's a toolchain lesson, prefer `runMode: 'terminal'` with realistic
   captured output; if it needs files, sandbox-forbidden features (`unsafe`,
   cgo), or multi-package code, the same.
